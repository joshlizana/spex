# Benchmarks

This directory contains selected generated benchmark summaries that provide reproducible portfolio evidence.

The development benchmark tool records local results as Markdown and generates a Markdown summary only when a run is explicitly selected for publication. Routine runs remain local and do not modify this directory. Each summary identifies the workload, captured-dataset metadata, environment, configuration, measurements, and limitations. Captured events and replay data marts remain outside Git.

Unpublished local results reside in the Git-ignored root-level `benchmarks/` directory.
